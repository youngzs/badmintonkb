## 训练方法详解

### 注意力训练方法

**舒尔特方格训练**
1. 准备5×5的数字方格(1-25随机排列)
2. 按顺序快速找出1-25
3. 记录完成时间
4. 目标: 30秒以内完成

**抗干扰训练**
1. 设置干扰环境(音乐、人声)
2. 完成技术动作或战术任务
3. 对比无干扰环境下的表现
4. 逐步提高干扰强度

### 放松训练方法

**深呼吸放松法**
```
步骤:
1. 舒适坐姿或站姿
2. 缓慢深吸气(4秒)
3. 屏息(2秒)
4. 缓慢呼气(6秒)
5. 重复5-10次
```

**渐进性肌肉放松法**
```
步骤:
1. 从脚趾开始依次到头部
2. 每个部位先紧张5秒
3. 然后放松10秒
4. 感受紧张与放松的差异
5. 全身放松后静坐2分钟
```

### 心理预演方法

**心理预演步骤**
```
1. 闭眼,放松身心
2. 想象比赛场景
3. 感受比赛氛围
4. 预演成功动作
5. 体验积极情绪
6. 慢慢睁开眼睛
```

## 家庭配合指导

### 家长支持要点

**营造积极环境**
- 理解孩子的情绪波动
- 避免过度施压
- 关注过程而非仅结果
- 提供情感支持

**配合训练要求**
- 督促完成每日训练
- 记录孩子进步
- 与教练保持沟通
- 参加家长培训

### 家庭训练活动

**每日活动**
- 睡前放松训练(5-10分钟)
- 积极自我对话练习
- 情绪日记记录

**周末活动**
- 家庭运动时间
- 观看比赛视频
- 讨论训练收获
