# 13-15岁专项期训练

## 年龄段特点

这个年龄段的运动员：
- 🏆 竞技能力显著提升
- 🎯 战术理解和执行能力增强
- 🏃 身体素质接近成人水平
- 🎨 形成个人技术风格

## 训练目标

1. **竞技水平提升** - 向高水平运动员迈进
2. **战术能力完善** - 掌握各种战术打法
3. **心理素质培养** - 提高比赛心理调控能力
4. **专项技术精进** - 形成技术特长和打法风格

## 📚 训练内容

### 技术训练 Technical Training

1. **[网前技术进阶](./technical-training/net-play-advanced.md)**
   - 搓球技术精进
   - 勾球技术要领
   - 推球技术训练
   - 扑球技术掌握
   - 网前球组合练习
   - 适合：有扎实基础

### 战术训练 Tactical Training

1. **[比赛策略分析](./tactical-training/match-strategy-analysis.md)**
   - 开局战术运用
   - 关键分处理
   - 对手分析方法
   - 战术调整策略
   - 适合：有比赛经验

### 心理训练 Mental Training

1. **[竞技心理训练](./mental-training/competitive-psychology.md)**
   - 注意力集中训练
   - 压力管理技巧
   - 情绪调节方法
   - 积极心态培养
   - 放松训练技术
   - 适合：所有水平

## 训练建议

### 频率与时长
- **每周**: 5-6次
- **每次**: 120-150分钟
- **休息**: 每周1天完全休息，注重恢复

### 注意事项
⚠️ **重要提示**:
- 重视技战术结合训练
- 加强心理素质培养
- 科学安排训练负荷
- 预防运动损伤和过度训练
- 平衡学业和运动

### 家长角色
👨‍👩‍👧‍👦 **家长应该**:
- 支持孩子的职业规划
- 协助处理学业和训练平衡
- 提供全面的后勤保障
- 关注心理健康和压力管理
- 理性对待比赛结果
