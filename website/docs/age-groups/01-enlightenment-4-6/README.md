# 4-6岁启蒙期训练

## 年龄段特点

这个年龄段的儿童：
- 🎈 充满好奇心和探索欲
- 🎯 注意力集中时间短（10-15分钟）
- 🏃 协调能力快速发展
- 🎨 喜欢游戏化的学习方式

## 训练目标

1. **培养运动兴趣** - 让孩子爱上羽毛球
2. **发展基础运动能力** - 协调性、平衡性、柔韧性
3. **建立良好习惯** - 遵守规则、团队合作
4. **安全第一** - 避免受伤，快乐成长

## 📚 训练内容

### 体能训练 Physical Training

1. **[协调性训练基础](./physical-training/coordination-training-basics.md)**
   - 手眼协调
   - 平衡木练习
   - 跳格子游戏
   - 适合：完全零基础

2. **[平衡能力训练](./physical-training/balance-training-basics.md)**
   - 静态平衡
   - 动态平衡
   - 平衡游戏
   - 适合：有一定运动基础

3. **[柔韧性入门训练](./physical-training/flexibility-training-basics.md)**
   - 动态拉伸
   - 趣味拉伸游戏
   - 静态放松
   - 适合：所有水平

## 训练建议

### 频率与时长
- **每周**: 2-3次
- **每次**: 30-45分钟
- **休息**: 保证充足睡眠和恢复

### 注意事项
⚠️ **重要提示**:
- 不要强迫孩子训练
- 以游戏为主，技术为辅
- 多鼓励少批评
- 避免过度疲劳
- 关注安全防护

### 家长角色
👨‍👩‍👧‍👦 **家长应该**:
- 陪伴和鼓励孩子
- 营造轻松氛围
- 尊重孩子意愿
- 及时补充水分和营养
