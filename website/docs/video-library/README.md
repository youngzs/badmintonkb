# 视频库

> **资源类型**: 视频教学资源 | **更新**: 2025-11-13

## 📹 视频库说明

本视频库提供羽毛球技术动作的视频教学资源,帮助运动员、教练和家长更直观地学习和理解技术要点。

## 视频分类

### [技术示范](./technique-demonstrations/)
标准技术动作的完整示范视频,包括:
- 基本握拍和站位
- 发球技术(高远球、小球、平高球)
- 后场技术(高远球、吊球、杀球)
- 网前技术(搓球、勾球、扑球、推球)
- 中场技术(平抽、挡网)
- 步法技术(米字步、启动步、并步、跨步)

### [错误纠正](./error-corrections/)
常见技术错误的分析和纠正方法视频:
- 握拍错误及纠正
- 发力方式错误及纠正
- 步法错误及纠正
- 击球点错误及纠正
- 身体姿态错误及纠正

### [高级技术](./advanced-techniques/)
进阶技术和战术运用视频:
- 假动作技术
- 快速连贯技术
- 战术组合演示
- 比赛实战分析
- 高级步法技巧

## 使用指南

### 观看建议
1. **初学者**: 从基本技术示范开始,反复观看并模仿
2. **进阶者**: 对照错误纠正视频,检查自己的动作
3. **高级运动员**: 学习高级技术和战术运用

### 学习方法
- **慢速播放**: 观察动作细节
- **分段学习**: 分解动作逐步掌握
- **对比练习**: 录制自己的动作对比学习
- **重点标注**: 记录关键技术要点
