### 高级步法技术详解

#### 1. 米字步完整训练法

**训练步骤**：

**第一阶段：单点练习（1-2周）**
- 前场正手位：垫步+跨步
- 前场反手位：并步+跨步
- 后场正手位：后退交叉步
- 后场反手位：后退并步

**第二阶段：两点组合（2-3周）**
- 前场↔后场
- 正手↔反手
- 对角线移动

**第三阶段：多点连续（3-4周）**
- 米字步完整练习
- 随机点位移动
- 实战模拟

#### 2. 启动速度优化

**关键技术点**：

```
准备姿势 → 重心前倾 → 脚掌发力 → 第一步爆发
```

**训练方法**：
1. 反应灯训练（提高神经反应）
2. 小范围折返跑（提升启动爆发力）
3. 弹力带阻力训练（增强腿部力量）

#### 3. 回中心技术

很多业余选手忽视了回中心的重要性。

**标准回中心动作**：
- 击球后立即准备回动
- 用小碎步快速回位
- 回到中心后调整重心
- 随时准备下一次移动

**常见错误**：
❌ 击球后站在原地
❌ 回中心时步伐过大
❌ 回位后重心不稳

**正确做法**：
✅ 击球瞬间就开始准备回动
✅ 小步快速移动
✅ 回到中心立即调整重心

#### 4. 实战步法组合

**单打常用组合**：

```
组合1：后场高远球 → 前场网前球
步法：后退交叉步 → 快速回中 → 垫步+跨步上网

组合2：前场扑球 → 后场防守
步法：跨步上网 → 快速后撤 → 后退并步

组合3：中场平抽 → 后场高球
步法：小碎步调整 → 后退步伐 → 起跳击球
```
