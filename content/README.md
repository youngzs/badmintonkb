# 训练内容 | Training Content

欢迎来到青少年羽毛球训练知识库！根据年龄选择合适的训练内容：

## 📚 按年龄段浏览

### [4-6岁 启蒙期](/content/age-groups/01-enlightenment-4-6/)
适合刚接触羽毛球的幼儿，重点培养运动兴趣和基础协调能力。

**训练重点**:
- 协调性训练
- 平衡能力
- 柔韧性
- 趣味性游戏

### [7-9岁 基础期](/content/age-groups/02-foundation-7-9/)
建立技术基础，发展专项运动能力。

**训练重点**:
- 基本握拍和步法
- 速度与敏捷性
- 反应速度
- 基础技术

### [10-12岁 发展期](/content/age-groups/03-development-10-12/)
系统技术训练，培养专项竞技能力。

**训练重点**:
- 高远球等核心技术
- 专项体能提升
- 双打战术基础
- 技术动作定型

### [13-15岁 专项期](/content/age-groups/04-specialization-13-15/)
竞技水平提升，全面战术训练。

**训练重点**:
- 网前技术进阶
- 竞技心理训练
- 比赛策略分析
- 高水平竞技
